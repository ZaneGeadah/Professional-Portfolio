WEB DEVELOPMENT · SEPTEMBER 2026

GT Movies Store

A movie storefront with a connected frontend and backend, built with Django.

I created GT Movies Store as a web app where users can log in, search for movies, write reviews, and edit or delete their own reviews. The app also includes a review-reporting action, a shopping cart, movie checkout, and an order history where users can keep track of their purchases.

Building it helped me understand how the pages users interact with connect to the Python code and stored data behind them.

PROCESS & REFLECTION

Learning the “why” behind the code.

01 / FOLLOWING THE PROCESS

Build with understanding.

I followed Django 5 for the Impatient: Learn the Core Concepts of Django to Develop Python Web Applications by Daniel Correa and Greg Lim.

What I loved about the book was how it explained why we wrote each line of code and made each decision. It helped me learn how HTML, CSS, and Python work together, instead of only showing me what to type.

02 / WORKING THROUGH ERRORS

Research, retrace, repair.

When I ran into a problem, I looked it up online and went back through the book’s steps. I compared those steps with my code to find where I might have made a mistake, then checked whether my change fixed the issue.

One recurring challenge was copying code from the book into VS Code. The pasted code sometimes introduced syntax or formatting errors. Working through those problems taught me to look carefully at the code itself, rather than assume that copying it meant it would work.

03 / SHARING THE RESULT

From my laptop to the web.

The process also taught me how to keep my project on GitHub and deploy the Django application through PythonAnywhere.

My biggest takeaway was that following a process still requires active problem-solving. Understanding each step made it easier to figure out what went wrong and gave me more confidence working across the frontend and backend.
